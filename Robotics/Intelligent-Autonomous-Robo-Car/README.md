Intelligent Autonomous Robo Car

An Arduino Nano based intelligent robotic car featuring autonomous navigation and Bluetooth remote control.

Features

- Autonomous Navigation
- Bluetooth Remote Control (HC-05)
- Ultrasonic Obstacle Detection
- IR Sensor Navigation
- LDR Based Sleep Mode
- OLED Display Interface
- Servo-Based Environment Scanning

Hardware

- Arduino Nano
- L298N Motor Driver
- HC-SR04 Ultrasonic Sensor
- HC-05 Bluetooth Module
- SSD1306 OLED
- IR Sensors
- LDR
- SG90 Servo
